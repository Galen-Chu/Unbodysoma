# 願景 Vision

## 一句話

**建立一個模擬人體引擎，讓心智能力從「維持一個身體活著」的需求中長出來，並且可以被觀測、被實驗、被重現。**

## 為什麼要做這件事

| 既有方向 | 有什麼 | 缺什麼 |
|---|---|---|
| 生理模擬引擎（如 HumMod、Pulse、BioGears） | 經驗證的器官系統模型 | 沒有心智，行為由外部腳本驅動 |
| 認知架構（如 ACT-R、Soar、LIDA） | 記憶、注意力、決策的計算模型 | 身體通常只是輸入輸出通道 |
| 大型語言模型代理 | 語言與推理能力 | 沒有需要維持的內在狀態，「情緒」只是文字風格 |
| 遊戲 / 虛擬人 AI | 可信的外在行為 | 內部是行為樹或手寫狀態機，缺乏因果機制 |

Unbodysoma 要填的是**身體與心智之間的因果迴路**：一個身體狀態會真的影響知覺與決策、而決策也會真的改變身體的系統。

## 核心假設

這些是本專案的工作假設，用來指導設計，不是已被證明的事實：

1. **心智的首要功能是調節身體（allostasis）。** 大腦最根本的任務是預測身體的需求並提前調節，而不是被動地反應刺激（Sterling, 2012）。
2. **情緒是被感知與詮釋的身體狀態。** 核心情感（valence / arousal）來自內感受訊號，再經由情境被建構成具體情緒（Damasio, 1994；Barrett, 2017；Seth, 2013）。
3. **身體會反過來塑造認知。** 喚醒度改變威脅評估、飢餓改變注意力與價值判斷——這些不是雜訊，而是設計重點。
4. **高階能力應該建立在低階調節之上。** 記憶、規劃、自我模型、語言是逐層加上去的，每一層都必須能回溯到它服務的身體需求。

## 設計原則

1. **一條迴路，不是兩個系統。** 身體與心智共用同一個時間軸與訊號匯流排，沒有「先跑生理、再跑 AI」這種切分。
2. **多時間尺度是一等公民。** 神經活動（毫秒）、心跳（秒）、荷爾蒙（分鐘到小時）、晝夜節律（天）必須能在同一次模擬中共存。
3. **模組可替換、保真度可分級。** 每個子系統都可以從玩具模型（L0）替換成文獻模型（L1）或經驗證 / 外部引擎（L2），而不改動其他模組。
4. **可觀測、可重現。** 給定相同的種子與情境，結果必須逐位元相同；每一個內部變數都能被記錄與檢視。
5. **先求閉環，再求精確。** 寧可先有一個粗糙但完整的迴路，也不要一個精緻但斷開的器官。
6. **誠實標示科學宣稱。** 每個模型都要標註其保真度等級與參考來源；未經驗證的就說未經驗證。

## 範圍與非目標

**在範圍內（長期）**

- 主要生理子系統的整合模擬（心血管、呼吸、代謝、內分泌、體溫、睡眠 / 晝夜節律、免疫）
- 由身體狀態驅動的驅力、情感、注意、記憶、學習與決策
- 可在模擬環境中行動的身體（感覺運動迴路）
- 研究與教學用的實驗平台：「如果改變 X，心智會怎樣？」

**明確不做（至少目前）**

- ❌ 醫療診斷、治療建議或任何臨床用途
- ❌ 宣稱系統「有意識」或「真的有感受」
- ❌ 細胞或分子層級的生化模擬
- ❌ 以大型語言模型作為心智核心——語言模型未來可以是**被身體狀態約束的**表達層，但不是驅動層
- ❌ 逼真的 3D 人體外觀或動畫

## 怎樣算成功

| 階段 | 成功標準 |
|---|---|
| 短期 | 最小生物體能在情境中表現出可解釋、可重現的身心耦合行為（例：恐懼反應、飢餓影響決策） |
| 中期 | 生理子系統能重現文獻中的典型反應曲線；心智層能從經驗中學習，且學習是由身體狀態驅動的 |
| 長期 | 研究者可以用 Unbodysoma 對「身體如何塑造心智」提出並測試可被反駁的假說 |
