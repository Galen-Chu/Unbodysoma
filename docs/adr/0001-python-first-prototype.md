# 0001. 以 Python 撰寫原型，核心零外部相依

- 狀態：已採用
- 日期：2026-10-17

## 背景

專案初期最大的不確定性在於**架構與模型本身**（要有哪些模組、怎麼耦合、哪些行為是對的），而不是執行效能。同時，目標使用者（研究者、學生）多半熟悉 Python，生理與認知建模的科學計算生態也以 Python 為主。

## 決定

- Phase 0–2 以 Python 3.11+ 撰寫。
- `unbodysoma.core` 與預設模組只使用標準函式庫；NumPy / SciPy 等只在確實需要的模組中以可選相依引入。
- 模組契約（`Module`、`SignalBus`）刻意保持極簡且與語言無關（純量訊號 + 宣告式讀寫），讓未來的原生核心可以沿用相同語意。

## 後果

- ✅ 迭代快、安裝零摩擦、容易閱讀與教學。
- ✅ 契約簡單，未來移植或跨語言轉接成本低。
- ❌ 單執行緒 Python 在模組數量與頻率增加後會成為瓶頸（目前 10 個模組、300 秒模擬約 0.04 秒）。
- 🔁 當效能分析顯示核心排程本身成為瓶頸時，評估以 Rust 重寫 Core 並透過 PyO3 提供 Python 介面，屆時另立 ADR。
