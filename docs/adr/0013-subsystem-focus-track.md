# 0013. 軌道調整：以身心子系統深化為主軸，沿生物組織尺度逐步扎根

- 狀態：已採用
- 日期：2026-11-18

## 背景

Phase 2 收尾時，原規劃的下一個里程碑 M1「N 個體 × M 世界」來自**世界架構**的路線：sanctuary-g-code 產生世界群、`run_population` 跑族群（ADR-0010 的延伸）。重新檢視後，專案的重心應是**完善各個身心子系統**——生理層的方法論（L0→L1→L2，文獻模型＋對照發表曲線的驗收測試）要延伸到心智層，並沿生物組織尺度（微生物級能力 → … → 人類級）逐步向下與向上擴展。世界與具身是支撐設施，不是主軸。

同時，VISION.md 原把「細胞或分子層級的生化模擬」列為非目標；實際的意圖是：**分子與細胞層級本來就是逐步模擬藍圖的一部分**，只是進場條件是「開發時實際能對照驗證」（有文獻或數據可作為驗收標的），且用語需要與現有的保真度分級清楚區分。

## 決定

1. **階段重劃**：Phase 3–6 改以生物能力帶組織——微生物級（非聯結學習與獎賞基礎）→ 無脊椎動物級（聯結學習與記憶）→ 脊椎動物級（注意、預測與規劃）→ 人類級（自我、語言與社會）。每一階段的完成標準都包含**對照文獻行為數據的驗收測試**（與 Phase 2 生理曲線驗收同一模式）。見 ROADMAP.md。
2. **身體不降級**：載體維持現有人體級 soma，不為了「微生物級心智」改做微生物身體；身體子系統的 L1/L2 深化持續進行，依心智實驗的需求從 BACKLOG 拉入（例如獎賞訊號需要能量池與血糖整合）。
3. **尺度與保真度兩軸分離**（ARCHITECTURE.md §5）：**組織尺度軸**（分子 → 細胞 → 組織/器官 → 器官系統 → 生物體 → 心智）描述模型描述的生物層級；**保真度軸**（L0/L1/L2）描述任一尺度內模型的可信度。目前主戰場在器官系統與生物體尺度；往分子／細胞尺度的扎根是長期方向，**進場條件是該尺度存在可對照的文獻或數據**（即能以 L1 起步），避免做不可驗證的空轉細節。
4. **VISION.md 措辭調整**：「細胞或分子層級的生化模擬」從非目標改為範圍內的**漸進扎根項**（受第 3 點的對照條件約束）；非目標保留「不做全尺度通用生化模擬器」。
5. **M1 降級為驗證儀器**：N 個體 × M 世界的組裝不再是里程碑，而是當需要分布級行為驗收（VARIABILITY 指標應用於學習曲線）或場所制約實驗場時才組裝的工具。sanctuary 世界群與族群執行器的投資保留，角色改變。
6. **原 Phase 4（3D 物理具身）移入支撐軌道**：依心智實驗的需求拉入，不再是獨立階段。

## 後果

- ✅ 心智層獲得與生理層相同的驗證紀律：每個能力階梯（PSYCHE.md 的 M 階梯，含新增的微生物級一階）都以可對照的行為數據驗收。
- ✅ REFERENCES.md 補上學習與制約的文獻地基（Rescorla–Wagner、Schultz、Kandel、線蟲、趨化），作為 Phase 3 的對照來源。
- ✅ 世界層投資不浪費：grid/sanctuary 世界成為制約與場所趨避的實驗場。
- ❌ 「具身於物理世界」的時程往後推，直到心智實驗需要 richer body 時才啟動。
- ❌ 階段編號改變，外部文件（若有）引用 Phase 4＝3D 具身者需注意此 ADR 之後的編號差異。
