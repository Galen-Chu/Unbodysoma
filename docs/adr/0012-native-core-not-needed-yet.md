# 0012. 原生核心：量測後決定暫不需要

- 狀態：已採用
- 日期：2026-11-16

## 背景

ROADMAP 開放問題 1：「Python 原型能撐到哪一個階段？何時、是否需要 Rust 核心？」Phase 2 的族群執行器即將把單次模擬乘上個體數，此問題需要數字而不是直覺。

## 量測（2026-11-16，Python 3.14，單執行緒）

| 項目 | 數值 |
|---|---|
| `grid_72h`（72 小時、網格世界、多速率） | 149 s ≈ **1741× 實時** |
| 完整測試套件（212 項，含多日模擬與重播驗證） | ≈ 11.5 min |
| 族群研究：100 個體 × 3 天 | ≈ 4.1 wall-hours（可程序級平行，線性加速） |

## 決定

- **Phase 2 與 Phase 3 期間維持純 Python**（零相依核心，ADR-0001）。
- 重訪觸發條件（任一成立即另立 ADR）：
  1. 單一研究需要的模擬量超過 ~10³ 個體日且等待時間不可接受；
  2. Phase 3 學習模組使每步成本上升一個數量級以上；
  3. 出現即時互動需求（UI 下維持 >1000× 實時）。
- 若觸發，路線順序：先量測熱點（多速率匯流排的每步拷貝是首選嫌疑）→ 該處批次化 → 仍不足才考慮 Rust 熱點模組經邊界層接入。

## 後果

- ✅ 開發速度與可讀性優先；族羣研究以平行程序即可承載。
- ✅ 效能主張有量測依據，此 ADR 可被未來的數字推翻。
- ❌ 即時互動（Phase 4 具身介面）預期會觸發重訪——屆時的量測應與本 ADR 的數字同表比較。
