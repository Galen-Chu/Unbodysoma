# 0003. 固定步長、多速率排程

- 狀態：已採用
- 日期：2026-10-17

## 背景

人體的時間尺度橫跨約七個數量級：神經活動是毫秒級，荷爾蒙是分鐘到小時，晝夜節律是天。用同一個步長跑所有模組會浪費大量運算在慢模組上；而完全的變步長 / 事件驅動排程則會讓決定性與除錯變得複雜。

## 決定

- 引擎以固定的 base tick（預設 `dt = 0.01 s`）推進。
- 每個模組宣告 `rate_hz`，每 `round(1 / (rate_hz · dt))` 個 tick 執行一次，並在**自己週期的結尾**被呼叫，傳入的 `dt` 為整個週期長度。
- 模組在兩次執行之間維持輸出不變（取樣保持）。
- 模組內部應使用在大步長下仍穩定的更新方式（例如一階系統的解析解 `relax()`）。

## 後果

- ✅ 簡單、完全決定性、容易推理。
- ✅ 慢模組幾乎不佔運算資源。
- ❌ `rate_hz` 會被量化成 base tick 的整數倍；非整除的頻率會被四捨五入。
- ❌ 不適合模擬數天到數年的長時間尺度（大多數 tick 只是在空轉）。若需要「快轉」，未來可考慮在快模組處於穩態時加大 base tick，或引入事件驅動排程，屆時另立 ADR。
