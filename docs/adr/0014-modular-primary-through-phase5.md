# 0014. 模組化維持主架構至 Phase 5 結束；預測編碼由內感受介面引入

- 狀態：已採用
- 日期：2026-11-26

## 背景

PSYCHE.md §3 的既有決定：「模組化（選項 A）起步，朝主動推論（選項 B）演進」，並約定在替換開始前重新檢視、另立 ADR。Phase 4 完成後，心智層已有：非聯結學習、雙軌道制約＋多巴胺 RPE、操作制約、情節記憶、場所記憶、晝夜預期（allostasis）與注意力廣播——選項 A 的地基比規劃此決定時豐富得多，且每個模組都有文獻錨點與自動驗收。此時評估是否開始整體替換為選項 B。

## 決定

1. **Phase 5 期間維持模組化為主架構**，不做整體的主動推論改寫。理由：
   - 行為驗收體系（300+ 測試、72 小時完成情境）是圍繞模組介面建立的；整體改寫會同時失去「可解釋」與「可對照文獻曲線」兩個本專案的核心方法論資產。
   - 主動推論的統一宣稱（變分自由能）目前在學界仍是框架而非可逐模組驗收的工程規格；把它當「必須採用的架構」會讓驗收標的失去锚點。
2. **以介面滲透的方式引入 B 的元素**：第一個落點是內感受介面的預測編碼（Seth 的內感受推論）——內感受訊號發布 `value` 與 `precision`（預測加權），下游模組（情感、驅力、學習）逐步改讀預測誤差而非原始值。這與 PSYCHE §3 早已預留的介面設計一致，且可以逐通道遷移、隨時以既有行為測試對照。
3. **比較的方法**：任何 B 版本的模組與 A 版本以**同一組行為驗收**比較（同一情境、同種子、族群分布指標），不另立標準。
4. **整體評估時點**：Phase 6（自我模型）開始前再次檢視；若屆時預測編碼介面已在三個以上模組落地且行為無退化，才考慮生成模型的整體組裝。

## 後果

- ✅ Phase 5 的注意力、allostasis 與既有學習模組在模組化架構內完成（本 ADR 不改變其範圍）。
- ✅ 預測編碼介面（value/precision）成為 Phase 5 後續或 Phase 6 的明確工作項，設計負擔從「改寫一切」降為「一次一個通道」。
- ❌ 「整個心智是一個生成模型」的理論純度延後取得——這是方法論選擇，不是技術限制。
