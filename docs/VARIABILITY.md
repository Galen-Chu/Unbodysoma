# 變異與統計真實性 Variability & Statistical Realism

> 狀態：**討論草案**（2026-10-20）。本文件記錄問題意識與候選參數，尚未形成決定；定案的部分會另立 ADR。

## 1. 起點：「從 1 到 10 隨機選一個數字」

請人隨口從 1 到 10 選一個數字，結果**不是**均勻分布：人類明顯偏好 7，並且避開 1、10 這種「看起來不夠隨機」的端點。請大型語言模型（LLM）做同樣的事，它也偏好 7，但偏好的程度**遠高於人類**——它不只學到了人類的偏好，還把**人類最常見的答案再放大**，同時壓縮了其他答案出現的機率。

結果是：LLM 的回答在「最典型」的意義上像人，在「分布」的意義上卻不像人。一群人的答案是散開的，一群 LLM 樣本的答案擠在同一個眾數上。

常見的解釋是：預訓練讓模型學到人類文本的分布（包括偏好 7），而偏好微調（如 RLHF）傾向獎勵「典型、安全」的回答，進一步降低輸出的熵，常被稱為 **mode collapse（眾數塌縮）**。

## 2. 為什麼這和模擬生物體有關

Unbodysoma 很容易犯同一種錯誤，只是形式不同：

| LLM 的現象 | Unbodysoma 中的對應風險 | 目前的狀況 |
|---|---|---|
| 眾數被放大 | 用文獻**平均值**當參數，模擬出一個「平均人」 | ✅ 存在：所有參數都是單一常數 |
| 不同樣本給出幾乎相同的答案 | 不同種子的生物體行為幾乎一樣 | ✅ 存在：雜訊只在感測器上，換種子幾乎不影響行為 |
| 機率最高的選項被當成唯一選項 | 行動選擇用硬門檻（argmax） | ✅ 存在：威脅 > 0.5 一定逃跑 |
| 輸出太「乾淨」 | 生理曲線平滑、沒有自然的波動 | ✅ 存在：心率是平滑的指數曲線，沒有心率變異 |

「平均人」不存在。1950 年代美國空軍量測四千多名飛行員的十項身體尺寸，發現沒有任何一人在十項上都落在平均附近的範圍內（Daniels, 1952）。一個所有參數都取平均值的模擬人，是一個**現實中找不到的人**。

更重要的是，在生理學中**變異本身就是健康的訊號**：健康的心跳並不規律，心率變異（HRV）降低與老化和疾病相關；生理訊號「複雜度的喪失」被視為老化的特徵（Lipsitz & Goldberger, 1992）。一個心跳完美規律的模擬人，不是理想化的健康人，反而更像是病人。

## 3. 目標：重現人類的分布，而不是平均，也不是均勻

這裡有兩個方向相反的錯誤：

- **太集中**（LLM 的錯）：只重現眾數或平均。
- **太均勻**（天真的修正）：把一切都換成均勻亂數。人類本身就不是好的亂數產生器——人在「隨機」產生序列時會刻意避免重複、過度交替（Wagenaar, 1972），而且這個能力會受認知負荷影響（Baddeley, 1966）。

**正確的目標是人類的分布本身，包括它的偏差。** 模擬的人在選數字時應該偏好 7，但偏好的程度、以及其他答案的散布，都要和真實人群相符。

## 4. 三種變異來源

討論參數時，必須先分清楚變異來自哪裡，因為它們的建模方式完全不同：

| 來源 | 意義 | 例子 | 建模方式 |
|---|---|---|---|
| **個體間**（between-individual，特質） | 不同的人本來就不一樣 | 靜止心率、壓力反應強度、焦慮特質、內感受準確度 | 每個個體從**族群分布**抽一組參數，模擬期間固定 |
| **個體內**（within-individual，狀態） | 同一個人每一刻都不一樣 | 心率變異、情緒起伏、注意力波動、決策的隨機性 | 有**時間結構**的雜訊過程（不是每一步獨立的白雜訊） |
| **量測 / 感知** | 感覺本身就不精確 | 對心跳的感知誤差、對威脅的誤判 | 感測器雜訊與偏誤（目前唯一有實作的部分） |

## 5. 候選參數清單

以下是目前程式碼中**應該從常數改成分布**的參數，以及未來需要新增的變異。「現值」是目前的預設值。

> 更新（2026-10-22）：所有參數現在都以 `ParamSpec` 宣告了預設值、單位、有效範圍與來源，完整清單見自動產生的 [PARAMETERS.md](PARAMETERS.md)。下表是其中對變異最關鍵的部分；尚未加入的是分布本身（分布族、標準差、相關）。

### 5.1 個體間（特質）參數

| 參數 | 位置 | 現值 | 需要的統計知識 |
|---|---|---|---|
| 靜止心率 | `Cardio.resting_bpm` | 65 bpm | 成人族群分布；與年齡、性別、體能的關係 |
| 最大心率 | `Cardio.max_bpm` | 190 bpm | 隨年齡下降（如 Tanaka 等人 2001 年的迴歸式 208 − 0.7 × 年齡），且個體間差異不小 |
| 心率對腎上腺素 / 運動的增益 | `Cardio.k_adrenaline`、`k_exertion` | 40、70 | 壓力反應性的個體差異 |
| 皮質醇基線與反應 | `Endocrine.cortisol_baseline`、`cortisol_gain`、`cortisol_tau_rise` / `cortisol_tau_fall` | 0.2、0.75、300 / 1800 s | 個體差異大；有晝夜節律（Phase 1 晝夜模組完成後才有意義） |
| 能量消耗速率 | `Metabolism.hours_to_empty_at_rest` | 16 h | 基礎代謝率的族群分布，與體重、體組成相關 |
| 喚醒對威脅評估的放大 | `Appraisal.arousal_bias` | 0.5 | 對應**焦慮特質**；族群中應呈現連續分布，高端對應焦慮傾向 |
| 情感基線與權重 | `Affect.baseline_valence`、`w_*` 權重 | 0.1；0.6 / 0.4 / 0.9 / 0.5 | 對應正向 / 負向情感特質；身體訊號在情感中的比重也因人而異 |
| 進食門檻 | `ActionSelection.eat_on` / `eat_off` | 0.4 / 0.1 | 飢餓與飽足感受的個體差異 |
| 逃跑門檻 | `ActionSelection.flee_on` / `flee_off` | 0.5 / 0.3 | 風險承受度的個體差異 |
| 內感受準確度 | `Interoception.noise` | 0.01 | 心跳覺察作業顯示個體間差異很大；且「客觀準確度」與「主觀自信」是不同的維度（Garfinkel et al., 2015） |

**參數之間有相關性，不能各自獨立抽樣。** 例如體能好的人通常靜止心率較低、最大攝氧量較高；焦慮特質與內感受的偏誤可能相關。獨立抽樣會產生現實中不存在的組合，所以族群模型需要描述**聯合分布**（至少是相關矩陣），而不只是每個參數各自的分布。

### 5.2 個體內（狀態）變異

| 變異 | 現況 | 需要的統計知識 |
|---|---|---|
| 心率變異（HRV） | 無：心率是平滑曲線 | HRV 的頻譜結構：高頻成分（約 0.15–0.4 Hz，與呼吸相關）、低頻成分（約 0.04–0.15 Hz）；常用指標如 SDNN、RMSSD 的正常範圍（Task Force, 1996） |
| 生理訊號的自然波動 | 無 | 有自相關的雜訊（如 Ornstein–Uhlenbeck 過程）、1/f 型態的長程相關，而不是每步獨立的白雜訊 |
| 情感的起伏 | 只有感測器雜訊傳進來 | 經驗取樣研究中情緒的個體內變異幅度與自相關（「情緒慣性」） |
| 決策的隨機性 | 無：硬門檻 | 見 5.3 |

### 5.3 行為輸出的分布

| 面向 | 現況 | 需要的統計知識 |
|---|---|---|
| 行動選擇 | 門檻 → 必定逃跑 | 機率式選擇（如 softmax 加溫度參數）；人類在某些作業中會出現**機率匹配**（probability matching），而不是總選最佳選項（Vulkan, 2000） |
| 反應時間 | 無（評估只有固定時間常數） | 人類反應時間呈右偏分布，常以 ex-Gaussian 描述（Ratcliff, 1979）；平均值相同但分布形狀不同，代表不同的機制 |
| 序列效應 | 無 | 人類的選擇有序列相依：避免重複、受前一次結果影響（Wagenaar, 1972） |

### 5.4 族群結構

年齡、性別、體能、晝夜型（早鳥 / 夜貓）等**族群層級的變項**決定了上述參數的分布。這部分需要先決定 Unbodysoma 預設模擬的是哪一個族群（例如「健康成人」），並明確寫出來，避免把某一個族群的平均誤當成「人類」。

## 6. 驗收要看分布，不只看平均

目前的行為測試都是「平均值落在某個範圍」。對變異的驗收需要分布層級的指標：

| 指標 | 定義 | 用途 |
|---|---|---|
| **眾數放大比** | 模擬中最常見結果的機率 ÷ 人類資料中同一結果的機率 | 直接量化「LLM 選 7」那一類的錯誤；理想值 ≈ 1 |
| **熵比** | 模擬分布的熵 ÷ 人類分布的熵 | < 1 太集中，> 1 太分散 |
| 分布距離 | KL 散度、Wasserstein 距離 | 整體形狀的比較 |
| 個體間變異係數 | 族群中某指標的標準差 ÷ 平均 | 檢查個體差異是否足夠 |
| 個體內變異與自相關 | 同一個體隨時間的標準差、自相關函數 | 檢查波動的幅度與時間結構 |
| 生理專用指標 | 例如 SDNN、RMSSD | 對照 HRV 的正常範圍 |

這類測試要用**固定種子、足夠大的樣本**來跑，避免測試結果時好時壞。

## 7. 與現有架構的關係

- **決定性不變。** 所有變異都來自有種子的亂數：個體由「族群種子 + 個體編號」決定，同一個種子永遠得到同一個人、同一條軌跡（[ARCHITECTURE.md](ARCHITECTURE.md) §6）。變異與可重現性並不衝突。
- **個體參數屬於模型，不屬於狀態。** 抽出來的特質參數在模擬期間不變，相當於 MuJoCo 的 `mjModel`；個體內的雜訊過程有自己的狀態，必須照 [ADR-0004](adr/0004-explicit-module-state.md) 宣告。
- **觀測層要擴充到族群層級。** 現在的 `RunWriter` 記錄的是一個個體；未來需要「同一情境 × N 個個體」的批次執行與分布統計。

## 8. 候選實作方向（尚未決定）

1. **參數規格**：每個可變參數除了預設值，還要描述分布族、平均、標準差、上下限、資料來源，以及與其他參數的相關。（🟡 已完成第一步：`ParamSpec` 提供預設值、單位、有效範圍與來源，見 [ADR-0006](adr/0006-declarative-parameter-and-signal-specs.md)；分布欄位尚未加入。）
2. **族群定義檔**：用設定檔（TOML）描述一個族群，例如 `healthy_adult`，可以從中抽出個體。
3. **結構化雜訊工具**：在 `core/` 提供 Ornstein–Uhlenbeck、粉紅雜訊等有時間結構的雜訊過程。
4. **機率式行動選擇**：以 softmax + 溫度取代硬門檻，溫度本身也是一個個體特質。
5. **族群執行器**：批次執行 N 個個體，輸出分布統計，並支援第 6 節的指標。

## 9. 對未來語言層的提醒

[PSYCHE.md](PSYCHE.md) 的 M7 層規劃了可選的 LLM 語言表達層。本文件描述的問題對它特別重要：

- 如果用 LLM 產生模擬人的自述或選擇，**眾數塌縮會讓所有模擬人說出幾乎一樣的話**，即使它們的身體狀態不同。
- 因此 LLM **不應該**負責需要符合人類分布的決策（例如在選項之間做選擇）；這些應由心智層的機率模型決定，LLM 只負責把已決定的內容轉成語言。
- 若 LLM 的輸出本身需要多樣性，必須用第 6 節的指標量測，並視需要採用提升多樣性的取樣方法，而不是假設它「自然像人」。

## 10. 待討論的問題

1. 預設要模擬哪一個族群？資料從哪裡來（公開資料集、文獻中的平均與標準差）？
2. 文獻常只報告平均與標準差，缺少相關矩陣時，要如何建立聯合分布？
3. 哪些參數的變異對行為影響最大？是否先做**敏感度分析**，再決定優先順序？
4. 行動選擇的溫度應該是固定特質，還是會隨狀態改變（例如疲倦時更隨機、壓力下更固著）？
5. 「人類的偏差」要重現到什麼程度？例如是否要讓模擬人在隨機作業中也偏好 7？
6. 分布層級的測試需要人類資料作為對照，要從哪一類實驗開始？
