# 身體層 Soma

身體層負責「需要被維持的東西」。它定義了心智存在的理由：如果沒有會偏離設定點的變數，就沒有驅力、沒有情感，也沒有需要做的決策。

## 1. 子系統規劃

| 子系統 | 主要狀態變數 | 對心智的意義 | 目前 | 候選 L1 模型 |
|---|---|---|---|---|
| 心血管 Cardio | 心率、心率變異、血壓、心輸出量 | 喚醒度最主要的內感受來源 | ✅ L1 速率動力學（雙路徑＋年齡天花板）；血壓／心輸出量仍無 | Guyton 循環調節模型 |
| 內分泌 Endocrine | 腎上腺素、皮質醇、胰島素、昇糖素、褪黑激素 | 壓力反應、能量動員、身心雙向橋梁 | ✅ L1 皮質醇（HPA 延遲＋甦醒反應＋負回饋）；腎上腺素 L0（秒級動力學） | HPA 完整模型（脈動分泌、糖皮質素受體動態） |
| 代謝 Metabolism | 血糖、胰島素、肝醣、脂肪、能量儲備 | 飢餓、疲勞、認知資源 | ✅ L1 血糖-胰島素（Bergman 最小模型＋雙區間腸道）；能量池仍 L0 | Dalla Man 膳食模型（完整膳食動力學） |
| 晝夜節律 Circadian | 晝夜相位、時鐘時間 | 警覺度、睡眠時機、荷爾蒙節律 | ✅ L0（無光照輸入的正弦節律） | 光照驅動的振盪器模型 |
| 睡眠恆定 Sleep | 睡眠壓力（process S） | 疲倦、睡眠時機 | ✅ L1 時間常數（Daan 等人，1984） | Borbély 雙歷程模型的完整版本 |
| 呼吸 Respiratory | 呼吸頻率、潮氣量、血氧、CO₂ | 窒息感、恐慌、呼吸調節情緒 | ⬜（目前只有固定的呼吸頻率帶動 RSA） | 化學感受器回饋模型 |
| 體溫 Thermoregulation | 核心溫度、顫抖、流汗 | 冷熱不適、行為性體溫調節 | ✅ L0（集總模型；尚無皮膚溫度） | Stolwijk 體溫調節模型 |
| 水分與電解質 | 體內水分、血漿滲透壓 | 口渴 | ✅ L0（單一水分儲備；尚無電解質） | — |
| 免疫 Immune | 發炎指標 | 生病行為（疲倦、退縮、食慾下降） | ⬜ | 細胞激素簡化模型 |
| 肌肉骨骼 | 肌力、疲勞、乳酸 | 費力感、運動成本 | ⬜ | — |
| 痛覺 Nociception | 組織損傷 | 疼痛、迴避學習 | ⬜ | — |

## 2. 目前的模型

以下方程式大多是**示意用的玩具模型（L0）**。`relax(x, x*, dt, τ)` 表示 x 以時間常數 τ 指數逼近目標 x*；`OU(τ, σ)` 表示平均為 0、標準差 σ、相關時間 τ 的 Ornstein–Uhlenbeck 過程（兩者都用解析解，任意步長下皆穩定）。
方程式中的數字都是預設參數值；每個參數的名稱、單位、有效範圍與來源見自動產生的 [PARAMETERS.md](PARAMETERS.md)。

### 2.1 心血管 `soma/cardio.py`（速率動力學：L1）

心率經**兩條動力學不同的路徑**上升（2026-11-16 升 L1）：快路徑是神經性反應（迷走退抑制與交感驅動——腎上腺素與運動開始時的第一拍跳升，秒級）；慢路徑是代謝性反應（心輸出量追上工作中的肌肉，Whipp & Wasserman, 1972 的基本分量，數十秒級）。天花板隨年齡縮減（Tanaka 等, 2001：208 − 0.7 × 年齡），恢復慢於上升（校準至 Cole 等, 1999 的一分鐘恢復判準）：

```
floor       = HR_rest − 8·sleeping                                （睡眠時靜止心率下降）
HR_max      = 208 − 0.7 × 年齡                                    （Tanaka 等, 2001；預設 35 歲 → 183.5）
快路徑目標    = floor + 40·adrenaline + 0.25·70·exertion            （τ = 5 s）
慢路徑目標    = 0.75·70·exertion（不得超過天花板餘裕）                （τ = 40 s 升 / 60 s 降）
HR̄          ← relax(快路徑) + relax(慢路徑)，總和鉗於 [floor, HR_max]
HR          = HR̄ + (1 − 0.8·adrenaline) · (3·sin(2π · 0.25 Hz · t) + OU(10 s, 2 bpm))
```

最後一行是**心率變異（HRV）**：呼吸性竇性心律不整（RSA，隨呼吸起伏）加上較慢的波動。腎上腺素會抑制 HRV，如同真實的交感神經活化。靜止時的短期指標約為 SDNN ≈ RMSSD ≈ 37 ms；壓力下 RMSSD 降到約 1 ms（`observe/metrics.py`、`tests/test_variability.py`）。

穩態增益與 L0 完全相同（運動 0.7 → +49 bpm；恐懼測試的行為因此不變）；變的是**過渡**：實測（`tests/test_cardio_l1.py` 驗收）——中等運動（exertion 0.7）第 15 秒完成最終升幅的 ~50%（快相）、63% 於 +20 秒、慢尾部到 60 秒仍有 ~20% 未完成（雙路徑簽名）；停止運動後第一分鐘下降 ~35 bpm（Cole 判準 ≥ 12）；80 歲個體的最大心率鉗於 152（Tanaka）。

### 2.2 內分泌 `soma/endocrine.py`（皮質醇：L1；腎上腺素：L0）

**腎上腺素（L0，秒級動力學與兒茶酚胺生理一致）：**

```
adrenaline ← relax(adrenaline, threat, dt, τ = 3 s（上升）/ 40 s（下降）)
```

**皮質醇（L1，2026-11-16）**：三個文獻錨點——急性壓力反應的延遲與峰值（Dickerson & Kemeny, 2004）、甦醒反應（Clow 等, 2010）、標準的 HPA 負回饋：

```
baseline  = 0.2 + 0.1 · cos(2π · (hour − 8) / 24)                （晝夜基線，晨 8 點最高）
喚醒脈衝：  sleeping 1→0 的瞬間 car₁ ← 1
car₁ ← relax(car₁, 0, dt, τ = 25 min)；car₂ ← relax(car₂, car₁, dt, τ = 25 min)
驅力     = threat · max(0, 1 − 4·(cortisol − baseline))          （負回饋：皮質醇越高，驅力越受抑）
acth    ← relax(acth, 0.45·驅力, dt, τ = 6 min（升）/ 25 min（降）)
cortisol ← relax(cortisol, baseline + 0.5·car₂ + acth, dt, τ = 10 min（升）/ 50 min（降）)
```

兩級串聯延遲（acth→cortisol）與甦醒脈衝的兩級積分，給出文獻曲線（`tests/test_endocrine_l1.py` 驗收）：

- **急性壓力**（30 分鐘、強度 0.9）：前 3 分鐘幾乎不動；**+23 分鐘達峰、+63%** of 基線（文獻：20–40 分、+50–90%）；壓力源結束後 1 小時內與對照組（同種子、無壓力）差值 ≤ 0.10、2 小時內 ≤ 0.05。
- **甦醒反應（CAR）**：自然睡醒後 **+59% 於 37 分**（Clow 等：+50–75% 於 30–45 分）。
- **持續壓力的負回饋**：2 小時持續威脅下皮質醇不飽和（< 0.7）並向平衡值回落（適應現象）。

皮質醇目前尚無下游讀者，是為記憶鞏固、免疫抑制、代謝等未來模組預留的慢速訊號（胰島素已由代謝 L1 內生建模，見 §2.3）。

### 2.3 代謝 `soma/metabolism.py`（血糖-胰島素：L1；能量池：L0）

**能量池（L0，Phase 1 不變——飢餓迴路依賴它）：**

```
drain    = (1 / 48 h) · (1 + 4·exertion + 3·shivering) · (0.9 if sleeping else 1)
reserve  ← clamp(reserve + (food_intake − drain)·dt)
```

48 小時的儲備（校準為一天約三餐）讓一天的消耗約為儲備的一半。能量攝取 `world.food_intake` 由環境層的 `world/food.py` 計算（`3×10⁻⁴ /s · world.food_available · motor.eating`）；飢餓迴路因此閉合：儲備下降 → 能量不足感 → 飢餓 → 進食 → 攝取 → 儲備回升。

**血糖-胰島素核心（L1，2026-11-16）**：結構採 Bergman、Ider、Bowden 與 Cobelli（1979）的最小模型；口服輸入採 Dalla Man、Rizza 與 Cobelli（2006）膳食模型家族的雙區間腸道；驗收範圍取 ADA（2021）正常值。方程（每分鐘速率）：

```
gut₁  ← gut₁ + food_intake · 2.3×10⁵ mg · dt                       （進食沉積口服葡萄糖）
flowᵢ = gutᵢ / τ_gut （兩區間串聯，τ_gut = 2100 s）
Ra    = flow₂ / V_G    （血漿出現率；V_G = 112 dL ≈ 1.6 dL/kg × 70 kg）
I     ← I + [k_sec·max(0, G − 100) − (I − I_b)/τ_I]·dt            （分泌與清除；I_b = 8 μU/mL，τ_I = 7 min）
X     ← X + [−p₂·X + p₃·(I − I_b)]·dt                             （延遲的胰島素作用；p₂ = 0.05/min）
G_b'  = 90 · min(1, reserve / 0.1)                                 （捱餓時防線潰堤——延續 L0 行為）
dG    = −(S_G + X)·G + S_G·G_b' + Ra + k_adr·adrenaline           （S_G = 0.026/min；k_adr = 2.5 mg/dL/min）
```

實際曲線（`tests/test_metabolism_l1.py` 驗收）：空腹 90（ADA 正常 70–99）；一餐（進食 750 s ≈ 52 g）峰值約 157 於 42 分（文獻 30–60 分）、2 小時 108（ADA 正常 < 140）、4 小時回到空腹 ±15 內；連續兩餐（≈ 83 g）峰值約 184，仍在健康範圍；胰島素峰值約 56–79 μU/mL、3 小時回基礎值。腎上腺素持續動員血糖約 +30–45 mg/dL（肝醣分解），與 L0 同量級。劑量校準（每單位儲備 2.3×10⁵ mg ≈ 一餐 55–60 g 醣類）使生物體自己的進食模式（含偶發的連續兩餐）全程不觸發 `glucose_abnormal` 警戒（72 小時情境驗收）。

**時間尺度的變化**：葡萄糖效能的時間常數 τ = 1/S_G ≈ 40 分鐘是文獻性質，因此捱餓造成的低血糖在第 2 小時才跌破 50 mg/dL——L0 的「1 小時內崩落」是快速追蹤的人工產物（`tests/test_feeding.py` 的捱餓測試已延長至 2 小時）。

**整合邊界**：血糖-胰島素核心目前供給內感受與健康監控，讀 `soma.endocrine.adrenaline`、吃同一條 `world.food_intake` 訊號；能量池仍是飢餓迴路的驅動——把儲備整合為淨葡萄糖平衡是後續工作（§3 的「讀寫同一組訊號」原則）。

### 2.4 晝夜節律 `soma/circadian.py`（process C）

```
drive = cos(2π · (hour − 19) / 24)        （晚上 7 點最高，早上 7 點最低）
```

模擬從 `start_hour`（預設早上 8 點）開始。人類內在週期平均約 24.2 小時（Czeisler 等人，1999）；目前沒有光照輸入，因此固定為已同步的 24 小時，時差與輪班要等光照感測模組加入後才能模擬。

### 2.5 睡眠恆定 `soma/sleep.py`（process S）

```
清醒：S ← 1 − (1 − S) · exp(−dt / 18.2 h)
睡眠：S ← S · exp(−dt / 4.2 h)
```

兩個時間常數來自 Daan、Beersma 與 Borbély（1984）。睡意與入睡 / 起床的門檻在心智層的 `Drives` 計算（見 [PSYCHE.md](PSYCHE.md) §4.3），因為那是大腦對 S 與 C 的解讀。門檻值是我們自己的校準（清醒 16 小時、睡 8 小時、約 23 點入睡），**不是**文獻數值。實際行為：每晚約 22:00–22:45 入睡，睡 7.3–7.9 小時，約 06:00 起床；剝奪睡眠後，壓力會累積到在下午強迫入睡（`tests/test_sleep.py`）。

### 2.6 水分平衡 `soma/fluid.py`

```
loss        = (1 / 48 h) · (1 + 2·exertion + 6·sweating) · (0.8 if sleeping else 1)
hydration   ← clamp(hydration + (water_intake − loss)·dt)
osmolality  = 285 + 40 · (1 − hydration)  mOsm/kg
water_intake = 2×10⁻³ /s · world.water_available · motor.drinking     （world/water.py；約 2 分鐘補回 0.24）
```

滲透壓是由水分儲備換算而來（L0 映射）：充分補水時約 285，在口渴開始出現的地方（水分約 0.7）約 297，與正常範圍約 285–295 mOsm/kg 的上緣相符。流汗會耗水，所以炎熱時體溫調節與水分平衡互相牽制。水分低於 0.15 時，健康監控發出 `dehydration` 警告。

### 2.7 體溫調節 `soma/thermo.py`

```
production = 2.25 · (1 + 2·exertion) + 4 · shivering        （°C/h）
loss       = 0.15 · (T − T_ambient) + 8 · sweating
dT/dt      = production − loss
shivering  = clamp((37 − 0.3 − T) / 0.8),   sweating = clamp((T − 37 − 0.2) / 0.8)
```

集總的核心溫度模型：靜止時在 22 °C 正好平衡於 37 °C。顫抖產熱但耗能（代謝讀取 `soma.thermo.shivering`），流汗散熱但耗水（水分平衡讀取 `soma.thermo.sweating`）。實際行為：13 °C 只帶來輕微不適；夜間 7 °C 待在戶外會穩定在約 36.3 °C 並強烈想回庇護所；5 °C 時持續顫抖、能量消耗增加；38 °C 時持續流汗、水分流失加快（`tests/test_water_heat.py`）。核心溫度超出 35–39 °C 時發出 `thermal_stress` 警告，超出 32–41 °C 為 critical。

第一版的參數讓 13 °C 就使核心每小時下降 4.5 °C，生物體因此吃到一半就冷得跑回家。我們把散熱放慢到約十分之三，以反映人體的大熱容量與血管收縮；這仍是 L0 校準值，不是文獻數值。

## 3. 從 L0 走向 L1 的工作方式

1. 在 `docs/` 中寫下要採用的已發表模型、方程式與參數表，並附上引用。
2. 實作新模組，**讀寫同一組訊號**（必要時新增訊號並更新 [SIGNALS.md](SIGNALS.md)）。
3. 加入行為測試：重現文獻中的典型反應（例：口服葡萄糖耐受試驗的血糖曲線形狀與峰值時間）。
4. 在模組 docstring 標註保真度等級，在 `ParamSpec.source` 標註每個參數的來源。
5. 除了平均值，也記錄參數的**族群分布**（標準差、範圍、與其他參數的相關）與個體內的**自然波動**，作為日後抽樣個體的依據（見 [VARIABILITY.md](VARIABILITY.md)）。

## 4. 外部生理引擎

Pulse Physiology Engine（Kitware）與 BioGears 都是開源、經驗證的全身生理引擎。與其從零重寫所有器官，長期可行的路線是：

- 以轉接器把外部引擎包成一個（或一組）`Module`，將其輸出映射到 `soma.*` 訊號；
- 自己實作的部分集中在**外部引擎沒有、但對心智重要的介面**：內感受、神經調節、身心雙向耦合。

此路線的取捨（授權、效能、時間步長對齊）會在實際進行時以 ADR 記錄。
