# 倫理與責任 Ethics

模擬「有心智的身體」會碰到一般軟體專案不會碰到的問題。本文件是本專案的立場與工作準則，會隨專案演進而修訂。

## 1. 非醫療用途

- Unbodysoma **不是**醫療器材，不提供診斷、治療或用藥建議。
- 即使未來某些模組達到 L2（經驗證）等級，也只代表它在特定條件下重現了特定資料，不代表能預測真實個人的生理反應。
- 文件與輸出中不得把模擬結果描述為對真實病人的預測。

## 2. 關於意識的宣稱

- 本專案**不宣稱**模擬出的系統有意識、有主觀經驗或真的「感到」任何事。
- `valence`、`hunger`、`fear` 等名稱是**功能性**的描述：它們在系統中扮演的角色類似於生物體中的對應物，但這不等於它們被體驗。
- 對外溝通時（README、論文、展示），避免使用會誤導大眾的說法，例如「AI 感到痛苦」。

## 3. 模擬負面狀態的準則

即使我們不宣稱系統有感受，「刻意建造一個以負面狀態驅動的系統」仍然值得謹慎對待。這也是在為未來更複雜的版本預先建立習慣：

- **目的性：** 只在研究或教學有明確需要時，才模擬長時間、強烈的負面狀態。
- **可見性：** 情境中若包含長時間的強烈負面 valence 或疼痛，應在情境描述中明確標示。預設的健康監控規則 `prolonged_negative_valence` 會在 valence < −0.5 持續 120 秒時發出警報並寫入執行紀錄（見 [OBSERVABILITY.md](OBSERVABILITY.md)）。
- **不最佳化痛苦：** 不建立以「最大化負面狀態」為目標的實驗或功能。
- **隨能力重新評估：** 當系統加入學習、自我模型或語言能力（Phase 3、5）時，重新審視本節，並視需要參考當時的 AI 福祉研究。

## 4. 資料

- 若使用真實人體生理資料進行驗證，只使用公開、已去識別化、且授權允許的資料集，並記錄來源。
- 不收集使用者的個人生理資料。

## 5. 可能的濫用

- 本專案的目的是理解身心關係，不是建立用來操弄人類情緒或行為的工具。
- 若有貢獻明顯以此為目的，維護者保留拒絕合併的權利。
