## 2. 引擎與效能

- **熱點剖析**：多速率匯流排的每步拷貝是首要嫌疑——ADR-0012 的重訪前置；量測優先於改寫。
- **族群平行執行**：`run_population` 目前序列（100 個體×3 天 ≈ 4 wall-hours）；程序池封裝不需要等 ADR-0012 的觸發條件。
- **測試套件 8 分鐘**：考慮 `pytest-xdist`（先評估引擎的全域狀態與淺拷貝風險）；`slow` 標記分層已存在，CI 可先用 `-m "not slow"` 分兩個 job。
- **CI 矩陣**：加入 Python 3.14（開發機已是 3.14，本地綠燈可代表 CI）。

## 4. 生態整合（跨專案）

- **M1：N 個體 × M 世界**——`run_population` × sanctuary-g-code 的 population mode；兩側基礎設施皆已就位，缺的是組裝（sanctuary 批次生成世界 → 每個體配一世界）。這是 VARIABILITY 分布驗收指標的第一次實戰。
- **世界 provenance 進執行紀錄**：外部產生器的（產生器、preset@版本、種子、SHA-256）寫入 `meta.json`（WORLDGEN.md 開放問題 3；ADR-0010 的可追溯鏈收尾）。
- **標本適配**：`runs/signals.csv` → specimen-g-code 的行為標本（其 Phase 4；M1 的資料直接成為可檢驗標本）。
- **族群參數 SD 的文獻精修**：VARIABILITY §4 的「校準合理值」換成有引用的分布（Tanaka 殘差、HRV 族群數據等）。
